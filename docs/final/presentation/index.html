More beds,
or better beds?

If the September 2020 wildfire smoke returned today, Multnomah County's shelter system would reach fewer than one unsheltered person in three. This model asks which fix actually works — and finds that the second-best intervention is free.

QuestionWhy three
scenarios

Each scenario answers what the last one measured

The three arms are not three guesses. Scenario A is a measurement, not a treatment — its only job is to reveal which constraint actually binds. It reported: capacity. So B relieves capacity and changes nothing else. B then revealed a second constraint, so C spends the identical total capacity differently.

Because B and C both hold system capacity at exactly 6,842 spaces, any B→C difference isolates where the marginal capacity sits, and nothing else.

A · Today

36 sites · 2,234 spaces

Every clean-air-capable facility the county actually operates, at its real geocoded address with its real capacity. A measurement of the present system.

B · More beds

36 sites · 6,842 spaces

Every real facility scaled by 3.0627× so the system holds one space per person. Locations untouched. Isolates capacity.

C · Better beds

46 sites · 6,842 spaces

Real facilities grow only 1.5×; the difference becomes ten new shelters at algorithmically chosen locations. Same total. Isolates placement.

What C does not do

C never moves an existing shelter. All 36 real facilities stay at their real coordinates — a real shelter system cannot be picked up and set down somewhere else. C only decides where new capacity goes.
Stage 1Population
6,842 people

Every resident is a separate person

The population count is the 2025 Tri-County Point-in-Time count: 10,526 people experiencing homelessness in Multnomah County, more than 65% of them unsheltered — about 6,842. Only the unsheltered are modelled, because only they are outdoors.

Each one is placed at one of 2,981 distinct real campsite-report locations and given an age, a sex, a mobility status, an asthma and COPD status, and their own walking speed, each drawn from a published source.

The line of code that protects the whole experiment

Repast shuffles agent execution order each tick using its default random stream — the same stream that placed every resident at their encampment. Drawing a single extra number from it would silently rewrite the entire population, and the result would look completely normal.

PopulationSampler.java:251 a private random stream
/**
 * @param seed the run's random seed; the attribute stream is derived from it
 *             deterministically but kept separate from Repast's default
 *             stream (see class doc).
 */
public PopulationSampler(long seed) {
    this.rng = new Random(seed * 1000003L + 17L);
}

/** Samples one resident. Call order defines the population for a given seed. */
public Attributes sample() {
    AgeBand band = AGE_BANDS[pick(AGE_WEIGHTS)];
    // Age uniform within the published band (01-POPULATION.md §3.2 Option A:
    // "sample age uniformly within published bands; zero invented structure").
    // A fitted continuous distribution was considered and REJECTED — nothing
    // constrains the within-band shape, so a curve would manufacture precision.
    int ageYears = band.lowInclusive + rng.nextInt(band.highExclusive - band.lowInclusive);

    Sex sex = SEXES[pick(SEX_WEIGHTS)];

    boolean mobilityLimited =
            rng.nextDouble() < (ageYears >= 55 ? MOBILITY_P_55_PLUS : MOBILITY_P_UNDER_55);
  1. The highlighted line is the whole safeguard. A dedicated Random seeded from seed × 1000003 + 17 means attribute draws never touch Repast's default stream. Verified consequence: adding the entire heterogeneity layer left the archived baseline byte-identical.
  2. The comment records a rejected alternative. Age is uniform within each published band because nothing constrains the within-band shape. Fitting a smooth curve would have looked more sophisticated and manufactured precision no source supports.
  3. Mobility carries an age gradient, but the local total is held exact. The two probabilities (0.1522 under 55, 0.3478 at 55+) come from borrowing the ratio in a California study while pinning the marginal to Multnomah's measured 19.2%.

Walking speed is where demography becomes access

Every other attribute is a reporting stratum. Speed is the only one that changes who reaches a bed — so it is the only one allowed to.

PopulationSampler.java:280 three evidence rules in eleven lines
double speed;
if (mobilityLimited) {
    // Boyce's impaired categories already embed a slower, less able
    // walker, so the COPD decrement is NOT stacked on top of them —
    // same no-double-counting rule that makes mobility a replacement
    // rather than a multiplier (03-MOVEMENT.md §3).
    speed = truncatedNormal(IMPAIRED_SPEED_MEAN, IMPAIRED_SPEED_SD);
} else {
    double mu = freeSpeedMean(ageYears, sex);
    if (copd) {
        mu = Math.max(SPEED_MIN_MPS, mu + COPD_SPEED_DELTA_MPS);
    }
    speed = truncatedNormal(mu, SPEED_CV * mu);
}
  1. Mobility limitation replaces the speed; it does not scale it. N(0.95, 0.32) m/s from Boyce, Shields & Silcock 1999. Multiplying an age×sex mean by a factor would have been easier and wrong.
  2. COPD is an additive −0.19 m/s, matching how the source reports it: Buekers et al. 2024, European Respiratory Review, 25 studies, 1,015 people with COPD vs 2,229 controls, usual gait speed −19 cm/s (95% CI −28 to −11). The authors rate the evidence low quality, so the registry carries the full CI as a sweep range.
  3. The two are never stacked. A resident who is both mobility-limited and has COPD gets Boyce's distribution only — the impaired categories already embed a slower walker.
  4. Asthma appears nowhere in this block. That is deliberate and searched-for: the literature supports lower physical activity among adults with asthma, but no quantitative gait-speed decrement exists. Borrowing COPD's number for symmetry would have manufactured a finding.

The trap that was avoided

The standard deviation comes from Bohannon 1997's within-population coefficient of variation (0.13) — never from the 2011 meta-analysis's confidence intervals. Those are between-study intervals; using them would understate the real spread of individual walking speeds by three to five times.
Stage 2The city
89,322 nodes

Real streets, and a real bug in them

Residents walk on Portland's actual street centrelines — 112,070 polylines forming an 89,322-node pedestrian graph, with every edge weighted by its geodesic length on the WGS84 ellipsoid rather than the shapefile's undocumented length column.

Then the graph turned out to be lying.

The wormhole defect

27 node identifiers were claimed by different street features at locations 9 to 18.5 km apart. The shapefile contains zero multi-part geometry, so this was a pure attribute defect in the .dbf. The effect: those edges weighed metres but spanned kilometres. Dijkstra under-costed them, agents routed through them, and then walked the gap in a straight line. Twenty-two of fifty agents had journeys inflated — travel ×15, inhaled dose ×3 — and shelter choice could be wrong, not merely shelter distance.

Stage 3Behaviour
state machine

When people leave, and what happens at the door

Residents shelter in place, accruing exposure, until two conditions hold at once: the air crosses 55.5 µg/m³ and somewhere is open to walk to. Then they walk the routed path at their own speed to the nearest shelter that still has room, re-evaluating whenever they are turned away.

GisAgent.java:299 the refusal bug, and its fix
if (pathIndex >= routePath.size()) {
    // Reached the shelter's street node: request admission (V12).
    if (targetShelter.isOpenAt(tick) && targetShelter.admit()) {
        state = State.SHELTERED;
        arrivalTick = tick;
    } else {
        // Filled since selection: the resident REMAINS at this
        // shelter's street node and re-plans from there next tick,
        // excluding full shelters (A-17 / Finding A: never re-plan
        // from the immutable start node — that walked refused agents
        // back to their encampment, inflating distance and dose).
        // Bounded to avoid livelock.
        currentNodeId = targetShelter.getGraphNodeId();
        targetShelter = null;
        routePath = null;
        pathIndex = 0;
        retargetCount++;
        if (retargetCount > MAX_RETARGETS) { state = State.REFUSED_ALL_FULL; }
    }

  1. The bug. A resident turned away used to re-plan from startNodeId, which is immutable and points at their encampment. They were standing at the shelter door, so every new route began by walking all the way back to where they started.
  2. Why it stayed hidden. At the 50-agent test scale no shelter ever filled, so the code path never executed and every byte-identity regression gate passed. It would have first appeared as a corrupted headline number at production scale.
  3. The highlighted line is the fix — the routing origin moves to where the resident actually is.
  4. It is now guarded arithmetically. Analysis check #38 asserts walked ≤ planned_route_m + snap_gap_m + 200 m for every agent. In the capacity-binding reference run — 250 of 400 agents refused at least once — the maximum unexplained distance was 8.9 m.

A second bug, found by adding a feature

Once real shelter opening dates were honoured, REFUSED_ALL_FULL being terminal meant residents turned away from the Convention Center on 10 September never tried Charles Jordan when it opened on the 11th — leaving 99 real beds at zero occupancy. Refusal is now a waiting state, re-evaluated every tick. It cannot livelock: capacity never grows and each shelter opens exactly once.
Stage 4Metrics
three quantities

Exposure, dose, and risk are not the same thing

This separation is the most important scientific correction in the project, and it is enforced structurally rather than by discipline.

GisAgent.java:54 a contract written as a comment
// ---- THREE DISTINCT QUANTITIES, DELIBERATELY NOT MIXED ------------------
// 1. EXPOSURE  (exposureUgM3h)  = SUM C(t)*dt              [ug/m3 * h]
//    Environmental concentration-time. Physics of the AIR. Verified against
//    raw EPA AQS data to a ratio of 1.0000. Untouched by this block.
// 2. INHALED DOSE (inhaledDoseUg) = SUM C(t)*IR(activity)*dt   [ug]
//    Physics of the PERSON: how much particulate mass actually entered the
//    airway. Differs from exposure only by ventilation rate, which depends
//    on ACTIVITY (walking vs waiting), not on diagnosis.
// 3. HEALTH RISK (healthRiskMultiplier) = a susceptibility weight.
//    Biology. Currently 1.0 for everyone because no defensible
//    population-specific coefficient exists (A-09, A-22). The slot exists so
//    that risk can never be silently folded into dose.
// The cardinal rule: ventilation is PHYSICS and may vary with activity;
// susceptibility is BIOLOGY and stays out of the dose term entirely.

if (smokeField != null && state != State.SHELTERED) {
    double c = smokeField.concentrationForTick(tick, minutesPerTick);
    exposureUgM3h += c * dtHours;
    double ventilationM3h = (state == State.EN_ROUTE)
            ? INHALATION_WALKING_M3H : INHALATION_RESTING_M3H;
    inhaledDoseUg += c * ventilationM3h * dtHours;
    if (c > UNHEALTHY_UGM3) { hoursAboveUnhealthy += dtHours; }
}
  1. Exposure is Σ C·dt — a property of the air. Recomputed independently in Python from the raw EPA file, it matches the model to a ratio of 1.0000.
  2. Dose multiplies by ventilation rate — 1.62 m³/h walking, 0.61 m³/h waiting (EPA Exposure Factors Handbook 2011, Ch. 6). The rate depends on activity and never on diagnosis.
  3. Risk is a separate multiplier that returns 1.0 for every resident, by design, so that biology can never leak into the physics.
  4. Accrual stops at SHELTERED and nowhere else. Residents who are walking, stranded, or turned away are all still outdoors and keep accruing.

Why the risk weights are switched off

The project's original design specified VWE = PM2.5 × RR_age × RR_comorbidity, with RRage = 1.45 for adults 65+ and RRCOPD = 1.80. Checking those citations against the publisher record found something worse than wrong numbers.

ClaimedCited toWhat the record says
RR age ×1.45Di et al. 2017 A real, excellent paper — but it reports HR 1.073 per 10 µg/m³, and its cohort is entirely aged 65+, so it cannot produce an age contrast at all.
RR COPD ×1.80"Anderson et al. 2013" No such paper exists. The nearest record is Atkinson et al. 2013 — a cardiovascular study with no COPD estimate.
RR asthma ×1.40Zanobetti & Schwartz 2009 Wrong journal, volume and pages; the real paper is a mortality time series that does not report asthma as an effect modifier.
RR under-18 ×1.22"GBD MAPS / Kloog 2013" Not a resolvable reference. "GBD MAPS" is a report series, not a paper.
Even with correct numbers, multiplying exposure by a relative risk is a category error — a relative risk is a ratio of outcome rates, not a multiplier on exposure. And no weight could ever be validated here, because no health outcome is simulated.

Independent check on the age question: Kondo et al. 2019's meta-analysis reports an elderly-to-adult relative-risk ratio of 1.008 (95% CI 0.996–1.020) across eight studies — a null result. The proposed 1.45 was not merely unsourced; the best available evidence says the true value is close to 1.

The resolution: weights are held at 1.0, and stratified reporting is the primary metric. Outcomes are reported separately for each group rather than collapsed into a weighted index that no source can justify.

Signal against noise

Every arm was run with nine random seeds — 27 runs in total. The largest seed-to-seed spread on "got inside" is 11 people; the smallest gap between two arms is 306. The between-arm signal is roughly 28× the within-arm noise, and no range overlaps between arms on any headline metric.

One detail falls out of the design as a free consistency check: could not reach any shelter is identical across all three arms within each seed (16, 16, 16 in seed 42). Those residents sit on street-graph components containing no shelter at all — no amount of capacity or re-placement reaches them, and the number varies only with which residents were sampled.

Adding beds alone widens the gap

This is the second finding, and it is the one a capacity-only analysis cannot produce. An evaluation that tracked only aggregate access would score scenario B as a near-total success.

Asthma shows almost no access penalty. COPD shows a large one. That asymmetry is not an omission — it is evidence the model is not inventing effects.

A diagnosis can only change an outcome here by changing movement, because diagnosis is never a dose multiplier. COPD carries a published gait-speed decrement; asthma does not. So COPD tracks the mobility pattern and asthma tracks the population average — which is exactly what an honest model should produce.

And the gap is narrowed, not closed. 14.3% of residents with mobility limitations are still outside in scenario C. Ten well-placed shelters are a large improvement, not a solution.

Stage 7Limits
what it can't say

What this does not claim

The claim is narrow and deliberate: for a fixed total capacity, placing new capacity at optimized locations outperforms enlarging existing facilities — under the modelled assumptions.

The calibration result, reported against interest

Against the one observed occupancy record — Street Roots, 16 September 2020: approximately 130 of 198 beds occupied — the historical reference configuration fills 198 of 198. That is a 1.52× over-prediction, attributed to the assumption that everyone knows the shelters exist. A local survey found 65% of unsheltered residents had never heard of them. Every "got inside" figure in this study is therefore an upper bound.

Named limitations

  • The ten new sites are street-network nodes, not buildings. No zoning, cost, staffing or air-filtration analysis stands behind them.
  • The 1.5× expansion factor, the choice of ten sites, and B's uniform 3.06× scale-up are policy parameters, not measurements. The comparison establishes direction; magnitudes would move with different values.
  • Two real facilities are missing entirely — Clinton Triangle (160 units, the largest single site) and Multnomah Safe Rest Village (28) — because neither publishes a street address. Real capacity is ≈207 people higher than modelled.
  • Ten day centres are excluded because none publishes a capacity. In a daytime smoke episode these are plausibly the most relevant clean-air spaces that exist, so scenario A understates daytime availability. This cuts against the paper's own framing and is stated anyway.
  • The PM2.5 field is spatially uniform — with two in-county monitors, any interpolation would manufacture gradients the data cannot support. Placement can therefore only help by reducing time outdoors, never by moving people into cleaner air.
  • The monitors are non-reference heated-inlet nephelometers, which likely understate true PM2.5 during a fresh wood-smoke event.
  • Encampment locations are 2025–26 complaint-driven reports used as a spatial proxy for 2020, so they carry visibility bias.
  • Sex and mobility distributions are 2019 inside an otherwise 2026 study; asthma and COPD prevalences are imported from Minnesota.
  • Admission is order-dependent: residents are served in shuffle order rather than by need. This matters most in scenario A, where capacity binds hard.
  • No health outcome is modelled. The study measures smoke exposure and inhaled mass. It does not predict illness, hospitalisation, or death, and does not claim to.
Stage 8Method
reproducibility

A run that cannot be reproduced is not a result

Every run writes a manifest carrying its seed, its git commit, the Java and Repast versions, every parameter value, a SHA-256 for each input file, and a flag for whether the working tree was clean. The protocol — commit the code first, then run, then verify the manifest — exists because it was violated twice and caught both times by audit.

OutcomeLogger.java:369 a flag that admits its own limits
/**
 * True when tracked model sources are newer than the recorded git HEAD, i.e.
 * the run may have executed uncommitted code. An audit found nine archived
 * runs stamped a commit that could not reproduce them; this flag makes that
 * condition visible in the manifest instead of silent. Heuristic and
 * deliberately conservative: it compares file modification times against the
 * HEAD ref's own timestamp, so it errs toward reporting "true".
 */
private static String gitWorkingTreeDirty() {
    try {
        File head = new File(".git/HEAD");
        if (!head.exists()) head = new File("../.git/HEAD");
        if (!head.exists()) return "\"unknown\"";
        /* ... resolve the ref, read its timestamp ... */
        return String.valueOf(newestFileTime(src) > headTime);
    } catch (Exception e) {
        return "\"unknown\"";
    }
}
  1. It exists because of a real failure. Nine archived runs were stamped with a commit that lacked the code which produced them — they had been run from a dirty tree. All nine were re-run from committed code.
  2. It is honest about being a heuristic. The comment says so, and says which way it errs: toward false alarms rather than false assurance.
  3. Three states, not two. It can return "unknown". A check that cannot answer says so instead of guessing.

Provenance

The model refuses to start if any variable claiming to be measured or literature-derived lacks a resolvable DOI, or if any literature value lacks a sweep range. A citation defect stops the simulation; it cannot quietly become a result. The registry holds 28 variables and 26 assumptions, four of which are marked blocking.
