Capacity Is Not Access

Clean-air shelter access for unsheltered residents of Multnomah County during the September 2020 wildfire-smoke event. Fatima Asghar, REU 2026.

  • Browser simulation

    The agent-based model ported to run in the browser, validated against the archived Java runs. Select a scenario and press Play. Shared links keep the configuration in the address.

  • Symposium deck

    The presentation. Use the arrow keys to move between slides.

  • Presenter script

    What is said on each slide, with the source for every number.

  • Repository

    Model, data provenance, analysis pipeline, archived runs, and the chapter source.

The simulation and the deck are the deliverables of a Research Experience for Undergraduates project. Every access figure is a model output under stated assumptions, not an observation of the real shelter system; the chapter and the deck say so where each figure appears.
